# 链路 ① 选品与素材采集

> 目标：在自有货盘内选出可卖的商品，并在短视频平台批量取得**与商品实物一致**的投放素材。
> 关键词：货源边界、基准可复现、判定口径、过滤漏斗、弃品阈值

---

## 一、链路总览

```
【选品】货源系统（限已合作供应商）
          │ 搜关键词 → 候选排序（月销优先）→ 定基准款
          ▼
   基准三件套：基准图 · 候选复核图 · 选中款全名
          │
【采素材】短视频平台
          │ 全名优先搜索 → 四层过滤 → 点击取视频ID → 无水印下载 → 转码
          ▼
   1品1夹归档 ──▶ 视觉核对（并排比图，像度 ≥90%）──▶ 通过 <5 条 → 弃品
```

**这一步失败的代价最高**：素材与实物不符，广告跑起来买家会看出货不对版，整单素材和后期的广告投入全部作废。所以本链路的所有设计都围绕一件事——**把"像不像"这个主观判断变成可复现、可留痕的规则。**

---

## 二、流程要点

### 阶段 1 · 选品

| 步骤 | 规则 |
|---|---|
| 在货源系统搜关键词 | **必须先勾选"已合作供应商"范围**——只在自己的货盘里选品 |
| 抓候选卡主图 | 用货源系统 CDN 图，**不用外部找图** |
| 候选排序定基准款 | 已合作 > 有供货价 > 品名命中；**月销纳入排序权重** |
| 产出基准三件套 | 基准图 + 候选拼图（选中款打红框标供货价）+ **选中款全名纯文本** |

**无已合作商品命中 → 报警停止，不降级放宽。** 选品边界是硬约束。

### 阶段 2 · 素材采集

| 步骤 | 规则 |
|---|---|
| 搜索 | **必须走 UI**（首页 → 推荐 → 搜索框 → 真实点击搜索）。直接改 URL 会被喂推荐流垃圾 |
| 搜索词序 | **选品全名优先** → 品名 / 品名+带货 / +推荐 / +好物。**严禁用"测评"** |
| 取视频 ID | 卡片 DOM 里没有 ID（藏在 React fiber）→ **真实点击卡片**，从浮层 URL 取 |
| 退回列表 | 用 Esc；`history.back` 会退过头 |
| 下载归档 | 无水印下载 → 转码 720×1280 → `1品1夹`，**视频与图片分目录，绝不混放** |
| 断点续跑 | 从文件名尾部提取已下载视频 ID **自动跳过**，重跑不重复下载（幂等） |

### 阶段 3 · 视觉核对（收工前必做）

| 步骤 | 规则 |
|---|---|
| 写基准特征 | 一两句写清参考图的形状/结构/材质/大小/人群定位 + 比对口径 |
| 抽帧 | **每条抽 5 帧**（10/30/50/70/90%），参考图放大置顶，一张图只放 4 条 |
| 逐条填表 | 相似度 / 判定 / 差异说明 **三列必填，禁止留空，禁止只报"全部通过"** |
| 存疑条 | 补抽多帧、单格放大到 ~250px 再判 |
| 剔除项 | 移入回收目录，再用精准长尾词补搜 |
| 阈值 | **通过 <5 条 → 弃品** |

## 三、设计要素

### 1. 判定口径：唯一指标 > 多指标清单

**最终口径：把参考图与素材画面并排看，只问一句「是不是同一个产品？像度 ≥90% 通过」。**

判定粒度是**款型级**，不是品类级：

| 差异类型 | 是否算不同产品 |
|---|---|
| 形状 / 结构 / 材质 / 大小 / 人群定位不同 | ✅ 算不同 → 剔除 |
| 颜色 / 图案不同 | ❌ 不算差异 → 通过 |

**这里走过一次弯路，值得记录**：最初尝试做「排除项清单」（列出所有不想要的款式特征），结果**人工判定质量反而下降**——因为列清单会诱导判定者只抓几个特征去套，漏掉整体形态差异。用户否掉了这条路线，改回"整体像不像"这一个主观但有效的口径。

> **经验**：能用单一整体指标表达的判断，不要拆成特征清单。清单看起来更"客观"，实际更容易漏判。

### 2. 标题不能作为判定依据

标题里出现"德绒""泡脚桶"等词，**不等于**画面里是同一款产品。

真实误判案例（首轮）：

| 条 | 标题 | 画面实际 |
|---|---|---|
| 1 | 【德绒保暖护腰】…透气护腰带 | 艾草内衬加宽款，非基准的素面薄款双兜 |
| 2 | 最实用泡脚桶没有之一 | 靴形高筒异形款，非基准的圆柱折叠桶 |
| 3 | 儿童泡脚桶 | 儿童款（画面字幕"宝宝可以放心用"） |
| 4 | 这是我买的…最好用的一款 | 全片为儿童使用场景 |

**四条全部因"标题反向误导"被误放**。修正后规则：**只看画面与参考图像不像，标题不作为判定依据。**

另有一处反向教训：某条素材画面出现红色大叉、标题写"泡脚袋"，被列为存疑；放大补抽 7 帧后确认——红叉是指向**传统硬木桶的错误示范**，该条实为粉色折叠过膝桶（像度 93%），应通过。
> **看到负面元素（红叉/打假/避雷）先确认它指向什么，再判定。**

### 3. 四层过滤漏斗

```
hit(品名) and not bad and not priced and dur_ok
```

| 层 | 规则 | 处置 |
|---|---|---|
| 1 **卖货** | 只收"正在卖这个产品"的视频 | 打假/测评/劝退/避雷类全部丢弃 |
| 2 **黑名单** | 打假、测评、智商税、避雷、别买、翻车、踩坑、骗局、假货… | 命中即丢并打印原因 |
| 3 **价格零容忍** | 标题带价格一律不要（`¥9.9 / 9块9 / 9毛 / 裸小数`）；排除 `1.5米 / 2.5kg` 等尺寸单位误杀 | 命中即丢 |
| 4 **品牌降级** | 品牌向内容 → 标 `[品牌·备选]` | **降级而非排除**：无品牌池收满才动用 |

**第 3 层的业务理由**：自己的定价与达人不同，素材里出现"9.9元3个"会让买家对不上价、伤转化。标题级用正则拦，**画面字幕里的价格要在视觉核对时人工过一遍**（无 OCR）。

**第 4 层的业务理由**：卖的是无品牌货，品牌口播会对不上。但素材总量有限，所以是**软约束**——优先无品牌，凑不够才兜底。

### 4. 基准可复现：必须留全名

人工搜同一个关键词会出十几款商品。**不给"选中款全名"，没人能复现"当初选的到底是哪一款"。**

所以基准图**必须**配一个纯文本的全名留存，它同时是短视频平台搜索的首选词。

> 这条体现的是：**自动化流程的中间产物必须可审计**，否则出错时无法定位是"选错了品"还是"搜错了词"。

### 5. 弃品阈值 + 误判自检

**通过 <5 条 → 弃品，不硬凑、不为凑数降标准。**

但弃品前必须先排除一个更可能的原因：**基准选错款**。

| 现象 | 优先怀疑 | 动作 |
|---|---|---|
| 剔除率 >70% / 0 条通过 | **基准选中了冷门款**，不是这个品没素材 | 换爆款款做基准，重跑一轮；仍不足再弃品 |

**支撑这条判断的是一个跨域洞察**：

> **短视频平台某类目的主流素材款型 ≈ 货盘里的爆款款型。**

实例：某品类基准选中"月销 100+ 的冷门款"，而平台的同类素材几乎全是另一种形态（对应货盘月销 2.3 万+ 的爆款）。结果采 15 条 **0 条对版**，整单作废。品本身没问题——货源有 16 款可选、含爆款，纯粹是基准选错了款。

**修正动作**：把月销纳入选款排序权重，选完先裁候选图对比"选中款 vs 该词下月销最高的款"，形态差异大就改用爆款做基准。

> **这条是整条链路里最有价值的发现**：它用**下游环节的分布特征，反向修正上游的选择规则**。选品时看不见的那件事（平台素材长什么样），在这里变成了选品规则的一部分。

### 6. 边界简化：溢出不硬扛

| 场景 | 处置 |
|---|---|
| 素材条数超过单次上限 | **直接截断，超出部分丢弃**。不做分批、不做筛选——超出部分无处安放，任何复杂逻辑都不产生价值 |
| 单条命令超时被杀（SIGTERM，非死机） | 素材通常已下载完、只差转码 → 走离线收尾模式（清残片 + 归档 + 补转码，不联网） |
| 前 8 张卡片标题均不含品名 | 判定为推荐流凑数 → **弃页换词** |

### 7. 交付物保护与目录契约

| 规则 | 原因 |
|---|---|
| `_` 前缀文件（基准图/核对图/全名）是**交付物**，重跑不得清除 | 靠命名约定存活；改清理逻辑时必须保留保护名单 |
| 视频与图片**必须分目录**，绝不混放 | 数据契约 |
| 每步跑完停下给用户确认（跑通后逐步放开） | 渐进式授权 |

## 四、异常与边界

| 场景 | 处置 |
|---|---|
| 关键词下无已合作商品 | 报警停止，回报用户（不降级放宽） |
| 前 8 张卡片均不含品名 | 推荐流凑数 → 弃页换词 |
| 剔除率 >70% | 先怀疑基准选错款 → 换爆款重跑 |
| 补搜后仍 <5 条 | 弃品 |
| 命令超时被杀 | 走离线收尾，不重下 |
| 画面字幕含避雷/打假/价格字样 | 标题过滤抓不到 → 视觉核对时人工补查 |
| 异品牌内容霸屏 | 视觉核对时主动点明，由用户拍板 |

## 五、效率

| 指标 | 数值 |
|---|---|
| 素材采集 + 视觉核对（整单） | **约 15–25 分钟/单** |
| 选品阶段 | 待补测 |
